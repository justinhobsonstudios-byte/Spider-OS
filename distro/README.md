# Spider OS Distribution

Spider OS 1.0 targets an Ubuntu 26.04.1 LTS foundation with selected Ubuntu Studio creative/audio components and KDE/Plasma technologies.

This directory will own:

- ISO assembly
- installer configuration
- package manifests
- Spider package build metadata
- apt repository configuration
- first-boot provisioning
- recovery image/boot entry
- release metadata

The legacy Aurora/bootc pipeline remains reference material until this path installs, reboots, and passes installed-system qualification.
