# Forage

Forage is Spider OS universal search and discovery.

Layers:

- `local/` — files, metadata, apps, settings, projects, Threads, activity
- `semantic/` — meaning-based retrieval
- `knowledge/` — relationship-aware Personal Knowledge Web search
- `deep/` — external research with provenance, citations, synthesis, and persistent research objects

Deep Forage supports Scout, Deep, and Expedition research depths. Local/private data must never be silently exported to external providers.
