# Spider OS Branding

Spider OS 1.0 uses the approved dark graphite/black visual system with purple/violet accents.

This directory will hold:

- canonical Spider OS marks
- boot and Web Assembly assets
- installer branding
- login branding
- workspace wallpaper assets
- iconography and theme tokens

Canonical workspace set:

- The Web
- Forage / Deep Forage
- Studio
- Art Lab
- Dev Bay
- Study
- Media
- Kali Bay
- System
- Recovery

The approved spider-and-dragon Kali Bay image is the canonical Kali Bay wallpaper and must not be silently substituted during packaging.
