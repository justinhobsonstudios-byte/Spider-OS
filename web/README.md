# The Web

The Web is the native Spider OS desktop/workspace experience built over KDE/Plasma foundations.

It owns:

- Home command center
- Spider menu/button and Web Rail
- workspace switching
- Anchors and Threads surfaces
- Webbie presence UI
- Forage entry points
- notifications grouped by Thread/meaning
- persistent workspace layouts
- multi-monitor workspace state

The Web should consume The Weave APIs and avoid owning core business logic.
