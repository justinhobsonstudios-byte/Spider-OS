# Spider OS Tests

Spider OS 1.0 tests are divided into:

- `unit/`
- `integration/`
- `installed-system/`
- `recovery/`

The installed-system test is release-blocking. It must boot the installer ISO, install to a virtual disk, eject the ISO, reboot from disk, reach The Web, and verify The Weave, Webbie, voice, Forage, Knowledge Web, Spider Control, workspace assets, networking, audio, Kali Bay manager, Recovery entry, and critical service health.

A successful ISO build or live-installer boot is not sufficient qualification.
