# Webbie

Webbie is Spider OS's persistent resident intelligence.

Planned modules:

- `runtime/` — lifecycle, watchdog, routing, verification
- `voice/` — wake word, speech-to-text, text-to-speech
- `reasoning/` — local/cloud reasoning orchestration
- `presence/` — proactive behavior, listening state, screen awareness
- `profiles/` — Everyday, Creative, Developer, Research, Security, System

Required wake phrases: `Hey Webbie`, `Webbie`, `Hey Web`, `Web`.

Voice is mandatory. Default voice direction is female Australian. Webbie acts through The Weave and verifies action results before reporting success.
