# Personal Knowledge Web

This area implements Spider OS's relationship-aware personal graph.

Core responsibilities:

- typed objects such as Anchors, Threads, projects, files, courses, songs, repositories, research, devices, people, and conversations
- typed relationships and provenance
- privacy classes: standard, private, restricted
- activity history
- high-confidence automatic linking and reviewable uncertain links
- persistence independent from any single UI

The Knowledge Web is consumed through The Weave and Forage rather than by direct UI database access.
