# Spider OS Brand

Spider OS is a local-first personal operating system built around one connected web of work, learning, creativity, security, and daily life.

## Core identity

- Product: **Spider OS**
- Desktop environment / shell: **The Web**
- Resident AI: **Webbie**
- Personal memory system: **Personal Knowledge Web**
- Startup sequence: **Web Assembly**
- Security workspace: **Kali Bay**
- Connected areas: **Anchors**
- Projects, ideas, and ongoing work: **Threads**

## Voice and presence

Webbie is represented by the crimson spider/web emblem rather than a human face. Her normal interaction style is proactive, dryly funny, concise when appropriate, and capable of both voice and text interaction. The intended voice is female with an Australian accent.

Canonical wake phrases are:

- `Hey Webbie`
- `Webbie`
- `Hey Web`
- `Web`

## Visual system

The primary palette is black, graphite, bone, and crimson. The Spider OS wordmark uses an architectural Gothic direction. Distressed, broken, or dripping texture belongs in artwork and key visual moments rather than being applied indiscriminately to every interface element.

The canonical tagline is:

**YOUR LIFE. ONE WEB.**

## Source-of-truth rule

Brand names in application code, desktop files, services, documentation, installer surfaces, and tests must remain consistent with this document and `docs/NAMING.md`.
